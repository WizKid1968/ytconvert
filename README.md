# YouTube to MP4/MP3 Converter

This is a simple web application built with Streamlit that allows you to convert YouTube videos to MP4 or MP3 format. You can also trim the videos to a specific length.

## How to Run

1.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

2.  **Run the Application:**
    ```bash
    streamlit run main.py
    ```

The application will open in your web browser, and you can start converting videos.

## Deployment

You can deploy this application online for free using Streamlit Community Cloud.

1.  **Push to GitHub:** Make sure your project is pushed to a public GitHub repository.
2.  **Sign up for Streamlit Community Cloud:** Go to the [Streamlit Community Cloud](https://streamlit.io/cloud) website and sign up using your GitHub account.
3.  **Deploy:** Click the "New app" button, select your repository, and deploy. Streamlit will automatically detect the `requirements.txt` file and install the necessary dependencies.
